# Specification 03: Evaluation Harness & The 10 Golden Cases

## 1. Evaluation Methodology (DeepEval CI/CD)
To guarantee zero-hallucination and anti-sycophantic performance in production, all agent outputs are evaluated in CI/CD using **DeepEval**:
- **Faithfulness Metric**: Threshold $\ge 0.95$. Every claim made by the agents must be grounded in the input JSON facts.
- **Hallucination Metric**: Threshold $\le 0.05$.
- **G-Eval Socratic Rigor**: Threshold $\ge 0.90$. Measures whether the 3 Fatal Questions are mathematically grounded and effectively challenge FOMO.
